# Web UI Structure

Web-only UI code lives here.

- `pages/` route-level screens
- `widgets/` page sections composed from common UI blocks
- `layouts/` web layouts (header/sidebar/page shells)
- `router/` route config and guards
- `providers/` web app providers/bootstrap
- `hooks/` web-only hooks
- `styles/` global and module style layers
- `assets/` web-only assets
- `lib/` web utilities/integrations
- `services/` web-only service adapters
- `tests/` web-specific test setup/helpers
